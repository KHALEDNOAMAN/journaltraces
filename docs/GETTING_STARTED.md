# Getting Started with JournalTraces

## What is JournalTraces?
A digital journaling platform that helps you track your thoughts, ideas, and daily reflections with structured templates and powerful search.

## Quick Setup
```bash
# Clone the repository
git clone https://github.com/journaltraces/journaltraces.git
cd journaltraces

# Install dependencies
npm install

# Start development server
npm run dev
```

## Your First Entry
1. Open the app at `http://localhost:3000`
2. Click **"New Entry"**
3. Choose a template (Daily, Gratitude, Goals, Free-form)
4. Write your thoughts
5. Add tags for easy search later

## Templates
| Template | Best For |
|----------|----------|
| Daily | Morning/evening reflections |
| Gratitude | 3 things you're grateful for |
| Goals | Weekly/monthly goal tracking |
| Free-form | Unstructured thoughts |
| Mood | Emotional check-ins with rating |

## Tips for Consistency
- Set a daily reminder (morning or evening)
- Start with just 2-3 sentences
- Use tags consistently (e.g., #work, #health, #ideas)
- Review weekly entries every Sunday
- Export monthly summaries for long-term reflection

## Privacy
All entries are stored locally by default. Your journal is your own.
